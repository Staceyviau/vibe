# Playa Paraíso — Tours & Locations à Playa del Carmen

Site vitrine (HTML/CSS/JS, sans dépendance) pour vendre des tours et promouvoir des locations touristiques.

## À personnaliser
- `script.js` : constante `WHATSAPP` (votre numéro, ex. `529841234567`)
- `index.html` : nom, téléphone, e-mail, tours, prix, logements, avis réels
- `style.css` : remplacer les dégradés `.t-*` / `.r-*` par vos photos (`background: url(photos/cenote.jpg) center/cover;`)

## Mise en ligne gratuite
GitHub → Settings → Pages → Source : branche `main`, dossier `/` (root).
